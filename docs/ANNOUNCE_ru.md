# SpiralQuant — Анонс (RU)

**🌀 SpiralQuant — синтезатор, который в реальном времени решает уравнение Шрёдингера.**

Каждый голос — настоящая 128-точечная комплексная волновая функция ψ(x),
эволюционирующая методом расщепления по времени (split-step Fourier). Никаких
прорисовок форм волны: вы строите квантовый «ящик», в котором живёт волна —
выбираете форму частицы, потенциал (гармоническая яма, барьер, двойная яма…) —
и слушаете, как волна колеблется, отражается, интерферирует сама с собой
**и туннелирует сквозь стены**.

🎛 **Что внутри**
- Квантовая эволюция в реальном времени на аудио-скорости — интерференция и есть тембр
- 6 форм волны × 6 потенциалов × 4 режима чтения (Re/Im/|ψ|/фаза) + звук из импульсного спектра (FFT)
- Квантовое туннелирование (прозрачность Гамова) — развивающиеся мерцающие хвосты
- Chord mode с чистой интонацией, транспозиция ±48 полутонов (±4 октавы), ADSR, фильтр, drive, 4 мастер-эффекта
- Живой осциллограф |ψ(x)| **и** спектр |ψ̃(k)| из реальных данных DSP — никаких фейковых анимаций
- 3 скина (Dark / SciFi Neon / Console), масштабируемый интерфейс, браузер пресетов
- VST3 + AU + Standalone, macOS universal / Windows / Linux
- 8 голосов ≈ 0,06× реального времени по CPU

Бесплатно и с открытым кодом. Попробуйте: *InfiniteWell + узкий гауссов пакет +
IMPULSE + TUNNEL* — и послушайте, как волна дифрагирует.
