# SpiralQuant — Руководство пользователя

**Квантово-механический wavetable-синтезатор.** Каждый голос — это настоящая
128-точечная волновая функция ψ(x), которая в реальном времени эволюционирует по
уравнению Шрёдингера. Вы формируете не форму волны, а *физику* ящика, в котором
волна живёт.

Форматы: VST3, Audio Unit (AU), Standalone. macOS (universal), Windows, Linux.

---

## 1. Установка

### VST3
Скопируйте `SpiralQuant.vst3` в:

- macOS: `~/Library/Audio/Plug-Ins/VST3/`
- Windows: `C:\Program Files\Common Files\VST3\`
- Linux: `~/.vst3/`

### Audio Unit (macOS)
Скопируйте `SpiralQuant.component` в `~/Library/Audio/Plug-Ins/Components/`
и выполните сканирование плагинов в DAW (или в Audio MIDI Setup).

### Standalone
Запускайте `SpiralQuant.app` (или исполняемый файл Windows/Linux) напрямую — хост не нужен.

---

## 2. Быстрый старт

1. Вставьте SpiralQuant на MIDI-дорожку и сыграйте ноту.
2. На панели волны показан |ψ(x)| — живая волновая функция первого активного голоса.
3. Поставьте **POT** в *Harmonic* (по умолчанию) или *InfiniteWell* — посмотрите,
   как пакет колеблется и отражается от стенок.
4. Уменьшите **STEP** (сэмплов на шаг эволюции) в панели WAVEFUNCTION: волна
   эволюционирует быстрее, тембр становится подвижнее.
5. Немного увеличьте **DT** — шаги крупнее, изменения резче.
6. Включите **TUNNEL** с потенциалом *Barrier*: волна просачивается сквозь стену,
   и звук получает развивающийся «реверберационный» хвост.

## 3. Вид интерфейса

```
+--------------------------------------------------------------+
| шапка: лого | версия/статус | браузер пресетов | LOAD SAVE DEL | скин |
+------------------------------+-------------------------------+
|                              |  WAVEFUNCTION                 |
|   ВОЛНА |ψ(x)| + ПОТЕНЦИАЛ   |  чипы: WAVE, FFT, QM, sample  |
|   СПЕКТР |ψ̃(k)|              |  ручки: SHIFT WIDTH IMPULSE   |
|   (гармонич. сетка, Гц)      |   DT STEP COLLAPSE QUAD ZENO SQUEEZE|
+------------------------------+-------------------------------+
|                              |  POTENTIAL                    |
|   ADSR (тяните ручки)        |  чипы: POT, TUNNEL            |
|                              |  ручки: CENTER WIDTH HEIGHT   |
|                              |    MEMORY LAG RING            |
+------------------------------+-------------------------------+
| HARMONY: чипы CHORD,         |  ENVELOPE: A D S R            |
| SUPERPOSE, WALK/EPR, тип     |  FILTER & DRIVE: CUTOFF RESO  |
| ручки PITCH и RATE           |    DRIVE SAT GAIN             |
|                              |  MASTER FX: тип/solo/LIMIT +  |
|                              |    DEPTH RATE FDBK MIX BITS   |
|                              |    CHAOS                      |
+------------------------------+-------------------------------+
| QUANTUM LAB (на всю ширину): GP SAT WKB PHASER PHASE AMT CHAR SIZE MIX |
| селектор лаборатории и симметрии обмена в титульной строке            |
+---------------------------------------------------------------------+
```

### Работа с контролами

- **Перетаскивание** ручки по вертикали (или горизонтали) — изменение значения.
- **Колесо мыши** над ручкой: 1% диапазона за щелчок; с **Shift** — 5%.
- **Двойной клик** по ручке: точный ввод значения (`55`, `1.2k`, `440 Hz`, `30%`).
- **Клик по верхней половине** панели волны переключает форму волны, по нижней —
  тип потенциала. Чип-кнопки делают то же самое и всегда показывают имя варианта
  из самого плагина (как его видит хост).
- **Ручки на осциллографе**: голубая = центр/ширина волны, янтарная = центр/высота
  потенциала, синяя = ширина потенциала. Они пишут те же параметры, что и ручки.
- **ADSR** — тяните маркеры прямо по графику огибающей.

## 4. Управление подробно

### Панель WAVEFUNCTION

| Орган | Что делает |
|---|---|
| **WAVE** (чип) | Начальная форма ψ: Gaussian, Sine, Cos, Parabola, Saw, Square. «Исходная волна», из которой стартует физика. |
| **SHIFT** | Где форма расположена в ящике (−1…+1). Не по центру = волна сразу в движении. |
| **WIDTH** | Ширина пакета / пространственная частота. Узкий = широкий спектр = ярче. |
| **IMPULSE** | Импульсный толчок e^(ikx): задаёт волне импульс — пакет бежит к стенке с начала ноты. |
| **DT** (`timestepDelta`) | Шаг интегрирования dt. Меньше — плавнее; больше — выразительнее скачки. |
| **STEP** (`samplesPerTimestep`) | Сколько аудио-сэмплов между шагами эволюции. Меньше — волна быстрее (и CPU больше), больше — медленный морфинг. Значения < 1 делают несколько шагов на сэмпл. |
| **COLLAPSE** (`jumpRate`) | Скорость фононного коллапса. Больше 0 — на каждом шаге ψ может случайно коллапсировать на оператор уничтожения â ψ с перенормировкой: стохастические «квантовые скачки звука», перкуссивные щелчки и гранулярный распад поверх плавной волны. 0 = чистая унитарная эволюция. |
| **QUAD** (`frftAngle`) | Поворот квадратуры считывания: 0 слушает ψ(x), 1 — волну импульса ψ̃(k), между ними — смеси дробного преобразования Фурье. Бесплатно (переиспользует последний FFT). |
| **ZENO** (`zeno`) | Квантовый эффект Зенона: с такой вероятностью каждый шаг выполняет измерение положения и проектирует ψ через узкое гауссово окно. «Наблюдаемая» волна замирает — большие значения прибивают пакет на месте (почти статичный тон), малые лишь замедляют бег. |
| **SQUEEZE** (`squeeze`) | Сжатые состояния, −1..+1: при нота-он ψ симпликтически перемасштабируется. Плюс сужает |ψ(x)| в пространстве (шире спектр импульсов, ярче транзиент), минус сужает в импульсе (длиннее и чище звон). Гейзенберга не обмануть — неопределённость переезжает, а не исчезает. |
| **FFT** | Заморозить эволюцию и читать ψ̃(k): спектр импульса становится звуком. Очень металлический/органный тембр. |
| **QM** | Главный тумблер эволюции. Выкл — волна замирает на текущей форме, голос становится обычным статичным wavetable. |
| **Sample mode** | Какая часть комплексной ψ идёт в звук: Real / Imag / Magnitude / Phase / PhononQND. Magnitude — ярко и «буззяще»; Phase — похоже на FM; PhononQND — лестница из 8 ступеней по амплитуде (квантовое nondemolition-считывание, щёлкает при пересечении уровней ψ). |

### Панель POTENTIAL

| Орган | Что делает |
|---|---|
| **POT** (чип) | «Ящик»: Flat, Harmonic, InfiniteWell, Barrier, DoubleWell, Linear. Задаёт, как волна ускоряется, отражается и интерферирует. |
| **CENTER / WIDTH / HEIGHT** | Позиция, масштаб и глубина потенциала. HEIGHT также задаёт порог «стены». |
| **TUNNEL** | Туннелирование Гамова `T = exp(−2κL)`: волна просачивается сквозь барьеры вместо жёсткого отражения. Длинные мерцающие хвосты. |

### Панель ENVELOPE

Классические A/D/S/R в мс (sustain — уровень). Пиковая громкость зависит от
velocity; частота ноты плавно скользит (glide) к цели в течение attack.

### Панель FILTER & DRIVE

На каждый голос: резонансный ФНЧ (CUTOFF, RESO), мягкий лимит DRIVE с
балансом SAT и усилением GAIN. Drive до фильтра агрессивнее; после — просто громче.

### Панель MASTER FX

Работает на сумме 8 голосов. Тип: Off / Flanger / Phaser / Bitcrush / Fractal.
При Off секция гаснет и полностью байпасится.

| Ручка | Значение |
|---|---|
| DEPTH | Время задержки / разброс фаз; у Fractal — сколько периодов тоники может охватить гребёнка |
| RATE | Частота модуляции (Гц); у Fractal — как часто гребёнка перестраивается |
| FDBK | Обратная связь |
| MIX | Сухой/мокрый |
| BITS | Разрешение биткраша (2–16 бит) |
| CHAOS | Фрактальная энтропия: насколько ярко звенит хвост и как далеко гуляет гребёнка |

**Fractal** — тонный хвост, а не генератор шума: хаос-карта выбирает длину
feedback-гребёнки, кратную целому числу периодов зажатой ноты (с учётом PITCH),
поэтому мокрый сигнал подкрепляет тонику и её гармоники. DEPTH задаёт размах — от
двух периодов до восьми, RATE — как часто гребёнка перескакивает на новую (медленно
означает одну связь на такты), CHAOS — насколько ярко звенит хвост. Уровень
нормирован обратной связью, так что эффект не может стать громче сухой смеси.

**Solo**: Full / только Dry / только Wet выход.

- **LIMIT**: лимитер мастера-выхода (включён по умолчанию). Стерео-связанный
  brickwall чуть ниже полного уровня: сорвавшиеся аккорды и пики drive
  прижимаются быстрой атакой и медленным релизом, выход гарантированно
  не выходит за ±1. Выключен = незащищённый сигнал (возможен клиппинг).

### Полоса QUANTUM LAB

Десять эффектов из исследования «квантовые эффекты в синтезе звука», собранные
в одну полосу на всю ширину окна. Четыре левые ручки действуют **на каждый
голос** — прямо на эволюцию Шрёдингера; четыре правые (AMT / CHAR / SIZE / MIX)
управляют **мастер-эффектом лаборатории**, выбранным в титульной строке (ряд
затемнён, когда лаборатория выключена). Второй селектор включает **симметрию
обмена** между соседними голосами.

| Ручка | Значение |
|---|---|
| GP SAT | Самодействие Гросса–Питаевского g\|psi\|^2*psi: спектральные пики расталкиваются — квантовый потолок насыщения (0 = линейная эволюция) |
| WKB | Туннельный фильтр: каждая мода импульса проходит виртуальный барьер с T = exp(-2*kappa*L); быстрые компоненты проходят, медленные отражаются — ВЧ-фильтр с ВКБ-скатом |
| PHASER | Дисперсионный квантовый фейзер: считывание зондирует волну после дополнительной свободной эволюции e^(-i*alpha*k^2); квадратичные фазовые нули движутся ручкой |
| PHASE | Глобальная динамическая фаза e^(-i*E*t/hbar): волновая таблица медленно орбитирует между считыванием Re и Imag (<H> измеряется по состоянию); при прокрутке POT CENTER дополнительно накручивается фаза Берри |
| AMT | Интенсивность лаборатории (посыл ревера / масштаб сдвига / глубина провала / спектральный потолок / уровень эха) |
| CHAR | Характер лаборатории, -100..+100%: беспорядок W / полутона (-12..+12) / частота событий / число мод / затухание фиделити |
| SIZE | Размер лаборатории: T60 (0.3-8 с) / время глайд-перехода / время восстановления / длина окна эха (60-1000 мс) |
| MIX | Сухой/обработанный баланс лаборатории |

**Симметрия обмена**: BOSE (+) добавляет голос соседа, прочитанный на фазе
скана самого голоса, конструктивно; FERMI (-) — вычитает. Нужно два и более
голосов — попробуйте вместе с CHORD.

**Anderson Reverb** — сеть из 16 линий задержки с ортогональным смешением
Адамара в контуре (замкнутая унитарная система). CHAR задаёт беспорядок длин:
W = 0 — точное гармоническое расстояние (металлический оттенок), большой W —
локализованные моды, плотный диффузный хвост. SIZE — T60, MIX — баланс.

**Adiabatic Pitch** сдвигает высоту двумя ганноверскими отводами. Само
отношение частот плывёт с длинной постоянной времени (SIZE) — адиабатическая
теорема: медленное изменение параметра переводит уровень E ~ 1/L^2 без щелчков.
CHAR — сдвиг (-12..+12 пт), AMT масштабирует его к нулю.

**Born Events** — пуассоновский движок событий, локальная частота которого
следит за сглаженной мощностью сигнала (громче = больше |psi|^2 = чаще
«измерения»). Каждое событие проваливает обработанный сигнал на AMT и
восстанавливается за время SIZE. CHAR — средняя частота.

**Mode Clip** — спектральное насыщение STFT на 256 точек: магнитуды выше
потолка AMT клиппируются, моды дальше CHAR (2..64) обнуляются — проекция
перегруженного сигнала на низшие энергетические моды. Тёплый «квантованный»
драйв с фиксированной задержкой ~5 мс.

**Loschmidt Delay** проигрывает последние SIZE сэмплов окна задом наперёд —
аудио-аналог эволюции с обращённым гамильтонианом U(-t) = U+(t), с затуханием
на краях окна и конвертом лосмидтовской фиделити exp(-G*t) (CHAR задаёт G,
AMT — уровень эха). Ритмичные реверсивные эхи с периодом окна.

### Полоса HARMONY

- **CHORD**: одна клавиша порождает строй с чистой интонацией. Консонантные
  наборы (Power, Major, Minor, Sus4, Major7) — малые целочисленные отношения;
  диссонантные (Tritone, Cluster, Pythagorean) — большие взаимно простые.
  Верхние ступени аккорда получают спад по velocity.
- **SUPERPOSE**: при включённом CHORD каждая нота звучит *двумя* конкурирующими
  строями сразу с весами cos²φ / sin²φ от случайной фазы. Отпускание клавиши —
  измерение: оно коллапсирует к одному победителю (вероятность cos²φ) и убивает
  проигравшего, поэтому одна и та же нота может разрешаться в разную гармонию
  на каждом дубле. Выкл — один выбранный строй.
- **PITCH**: глобальная транспозиция ±48 полутонов (±4800 центов) как 2^(cents/1200).
- **EPR**: запутанные голоса (нужен COLLAPSE > 0). Голоса одной MIDI-ноты
  (например, два варианта SUPERPOSE) ведут себя как одна ЭПР-пара: квантовый
  скачок на одном партнёре мгновенно применяет тот же коллапс остальным в том
  же блоке — они схлопываются в согласованные состояния вместе. Каскада нет:
  принудительные коллапсы не перезапускают распространение.

## 5. Пресеты

- Комбо в шапке показывает фабричные пресеты (вшиты в сборку) и ваши.
- **LOAD** — применить, **SAVE** — записать `.sp303preset` JSON в папку
  app-support, **DEL** — удалить пользовательский.
- В пресет сохраняются все параметры, **включая выбранный скин**.

## 6. Скины

Комбо в шапке (Dark / SciFi Neon / Console / Golden) меняет только цвета, никогда —
звук или поведение. Выбор сохраняется в состоянии плагина.

## 7. MIDI

Работают любые note on/off; 10-й канал не особенный. С включённым chord mode
одна нота порождает несколько голосов — помните про лимит 8 голосов: старше/тише —
украдётся первым.

## 8. Производительность

- CPU определяют FFT: важна скорость эволюции (STEP) и DT, а не количество ручек.
- Осциллограф перерисовывается только когда данные движка реально меняются
  (опрос 30 Гц по счётчику последовательности).
- Ориентир (`SpiralQuantTests --bench`): ~645 мкс на блок 512 сэмплов 48 кГц
  с 8 активными голосами на Apple Silicon.

## 9. Проблемы и решения

| Симптом | Решение |
|---|---|
| Нет звука | Поднимите GAIN, проверьте, что хост шлёт MIDI. QM выкл — не тишина: волна просто замирает. |
| Звук статичный | STEP слишком велик (волна эволюционирует медленно) — уменьшите, или выключен QM. |
| Резко/«буззит» | Sample mode Magnitude с узкой WIDTH; убавьте DRIVE или откройте CUTOFF. |
| Волна «плоская» | У square/saw амплитуда так и выглядит — это и есть форма. Сыграйте ноту и смотрите эволюцию. |
| В спектре «—» | Подписи Гц появляются после первой сыгранной ноты (f₀ берётся из неё). |
